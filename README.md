# IRON DUNE · 铁砂行动

[立即游玩 / Play now](https://ai8458.github.io/iron-dune/)

一个在浏览器中运行的第一人称坦克游戏。驾驶 M–04，清除三波共 12 辆敌方坦克，守住沙漠前哨。

| 操作 | 按键 |
| --- | --- |
| 驾驶 | WASD |
| 瞄准 | 鼠标 / 方向键 |
| 开火 | 左键 / 空格 |
| 瞄准镜 | Q / 右键 |
| 加速 | Shift |
| 暂停 | Esc / P |

主炮自动装填，弹药无限；每波结束修复部分装甲。支持战术雷达、炮塔后坐力、战场音效和战绩结算。

使用支持 WebGL 2 的桌面浏览器及键盘鼠标游玩。页面为静态文件，无需账号或后端服务。

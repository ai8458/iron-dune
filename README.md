# IRON DUNE · 铁砂行动

[立即游玩 / Play now](https://ai8458.github.io/iron-dune/)

一个在手机和电脑浏览器中运行的第一人称坦克游戏。驾驶 M–04，清除三波共 12 辆敌方坦克，守住沙漠前哨。

## 手机操作

- 左侧摇杆：前进、倒车和转向。
- 滑动战场：转动炮塔瞄准。
- 右下角开火：按住连续射击；按住按钮滑动可边瞄准边射击，用两个拇指同时驾驶和战斗。
- 瞄准镜、加速：轻触切换。
- 右上角：暂停、游戏设置和全屏；暂停后可返回指挥室。

横屏与竖屏均可游玩，进入战斗后自动铺满屏幕。手机默认使用省电画质，设置中可调整画质、灵敏度或手动开关触控按钮。触摸被取消、松手、旋转屏幕和暂停时会释放输入。

## 电脑操作

WASD 驾驶，鼠标或方向键瞄准，左键或空格开火，Q / 右键开镜，Shift 加速，Esc / P 暂停。

主炮自动装填，弹药无限；每波结束修复部分装甲。支持战术雷达、炮塔后坐力、战场音效和战绩结算。

使用支持 WebGL 2 的现代浏览器。页面为静态文件，无需账号或后端服务。
